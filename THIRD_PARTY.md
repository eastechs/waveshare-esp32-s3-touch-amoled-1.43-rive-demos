# Third-party sources

| Source | Use in the demos |
| --- | --- |
| [rive-framebuffer](deps/rive-framebuffer) | Renders live Rive artboards for the player and thermostat. Its dependency notices cover the pinned Rive runtime, ThorVG and the C bridge. |
| [waveshare-round-amoled](deps/waveshare-round-amoled) | Provides display and sensor support. Its setup script retrieves the Waveshare driver files and its notices identify the hardware dependencies. |
| [Inter](https://rsms.me/inter/) | The thermostat and VU meter use outlined labels from Inter Regular and Bold. The optional art generators read the font files from the pinned runtime test assets. Inter is distributed under the SIL Open Font License 1.1. |
